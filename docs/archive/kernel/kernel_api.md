## FFI Files — What Exists and Who Reads It

Lucid has two runtime modes — **interpreter** (run) and **compiler** (build) — and each mode needs the kernel's C API in a different form. This section documents every file in the FFI layer, what it contains, and which mode consumes it.

The principle throughout: the C headers are written manually and deliberately — only the subset of each library that Lucid game developers actually need is exposed, not the full library surface. If a capability is missing, it can be added later as an explicit decision rather than discovered as an accidental omission from a tool-generated file.

---

### The C Headers (`kernel/include/lge_*.h`)

**Written by:** engine team, manually.  
**Read by:** both compiler mode and interpreter mode (indirectly, via the FFI artifacts they generate).  
**The rule:** only functions that Lucid game developers or extension authors actually need are exposed here. Internal setup calls, library configuration, and capabilities not yet needed by the engine stay inside the `.cpp` files and never appear in a header. They can be promoted to a header later as an explicit decision.

Each header covers exactly one subsystem. They are the single source of truth for the entire FFI layer — `lge_ffi.lfi` is derived from them.

Three headers are engine-internal and do not appear in `LGE_GetAPI()` or either FFI artifact:
- `lge_imgui.h` — ImGui is used only by the engine's own C++ shell panels, never by Lucid code
- `lge_security.h` — security and license checks run at boot, not callable from scripts
- `lge_platform.h` — OS abstraction used only inside the kernel, invisible to everyone outside

---

### Compiler Mode — `lge_ffi.lfi`

**Format:** Lucid source file containing `@[foreign("C")]` declarations — valid Lucid syntax, no special format.  
**Generated by:** `lge_header_parser` (a build-time tool that reads the C headers via libclang).  
**Read by:** `luc_compiler` (AOT) and `luc_interpreter` (ORC JIT) — both ingest this file as a normal Lucid module at startup. The AOT compiler resolves symbols at link time; the ORC JIT registers them with its dynamic linker via `dlopen` at runtime. Neither mode requires a separate runtime symbol table.  
**Lives at:** `kernel/ffi/lge_ffi.lfi`

Both execution modes consume the same `.lfi` file. There is no separate interpreter-only format — the grammar's `@[foreign("C")]` declaration is the single source of truth for both the JIT and the AOT compiler.

The `lge_ffi.lfi` is checked into source control alongside the C headers. When a new function is added to a header, `lge_header_parser` is re-run and the updated `.lfi` is committed. Both the ORC JIT and the AOT compiler pick up the new symbol on next startup/build.

### Summary Table

| File                     | Written by                      | Read by                                            | Mode                   |
| ------------------------ | ------------------------------- | -------------------------------------------------- | ---------------------- |
| `kernel/include/lge_*.h` | Engine team, manually           | `lge_header_parser` (build step)                   | Both (source of truth) |
| `kernel/ffi/lge_ffi.lfi` | `lge_header_parser` (generated) | `luc_interpreter` (ORC JIT) + `luc_compiler` (AOT) | **Both**               |
| `luc_kernel.dll`         | C++ compiler (built)            | Both at runtime                                    | Both                   |

**Adding a new function to the API:**
1. Add it to the appropriate `lge_*.h` header manually
2. Implement it in the corresponding `.cpp` file
3. Run `lge_header_parser` to regenerate `lge_ffi.lfi`
4. Commit all three changed files together

Every function listed here is part of the kernel's public **C ABI** — exposed through `lge_api.h` and accessible to both C++ extensions (via `LGE_GetAPI()`) and Lucid code (via the `api` object passed to `on_load`). The document is organized by subsystem, matching the header files under `kernel/include/`.

Each subsystem section follows this structure:
- **Header file** — which `.h` to include
- **Lucid namespace** — the `api.X` equivalent for Lucid callers
- **Types** — handle types and POD structs introduced by this subsystem
- **Functions** — every callable, with parameter notes and return values
- **Notes** — constraints, threading rules, and things to watch out for

### The C Wrapper Rule

**Lucid only speaks C. It never speaks C++ directly.**

The kernel internals are written in C++ (Jolt Physics, ImGui, RmlUI, STL containers, etc.) because C++ is the right tool for high-performance engine code. However, C++ is too unpredictable to expose across a DLL boundary — name mangling, vtable layout, exception handling, and ABI differences between compilers and versions make it a fragile surface for interoperability.

The solution is a strict three-layer model:

```
┌─────────────────────────────────────────┐
│         Lucid Code / Extensions         │  ← speaks only C
├─────────────────────────────────────────┤
│         C Wrapper Layer (lge_*.h)       │  ← plain C: no classes, no virtual,
│    extern "C" { ... } around all        │    no exceptions, no STL, no using
│    public symbols                       │
├─────────────────────────────────────────┤
│      C++ Kernel Internals               │  ← Jolt, ImGui, RmlUI, STL internals
└─────────────────────────────────────────┘
```

**Rules enforced on every public header (`lge_*.h`):**

- No `class` or `struct` with methods — only POD structs (data only, no member functions)
- No `virtual`, no inheritance, no `= 0`, no destructors
- No C++ `using X = Y` aliases — use C `typedef` instead
- No STL types (`std::string`, `std::vector`, etc.) in any function signature
- No C++ exceptions — errors are return values (`int`: 1 = success, 0 = failure) or output parameters
- All function pointer types defined with `typedef`, not `using`
- All public symbols wrapped in `extern "C" { }` in the implementation `.cpp` files

Every public header starts with the same preamble:

```c
#pragma once
#include <stdint.h>   // uint32_t, uint64_t, int32_t ...
#include <stddef.h>   // size_t
#include <stdbool.h>  // bool, true, false  (C99 — required for all targets)

#ifdef __cplusplus
extern "C" {
#endif

// ... declarations ...

#ifdef __cplusplus
}
#endif
```

`bool` is used throughout (C99 `<stdbool.h>`) rather than `int` flags — all engine targets require C99 or later. Where a `bool` parameter or return is semantically a flag rather than a true/false (e.g. `LGE_SendFlags`), a named `typedef uint32_t` bitmask is used instead.

Where C++ patterns like "swappable provider" or "interface" are needed (e.g. the network backend, the license verifier), they are expressed as **C structs of function pointers** — the same pattern used by Vulkan's `VkAllocationCallbacks` and OpenAL's driver backend.

## 1. Core / Boot (`lge_core.h`)

**Lucid namespace:** `api.kernel`

The entry point into the kernel. Called once by the platform bootstrap (`LucidEditor.exe` or a shipped game's `.exe`). Not available to extensions or game scripts — this is engine-internal only.

### Types

```c
struct LGE_BootConfig {
    const char* window_title;       // displayed in the OS title bar
    uint32_t    width;              // initial window width in pixels
    uint32_t    height;             // initial window height in pixels
    const char* asset_bundle_path;  // path to .pck bundle, or a directory in dev mode
    const char* entry_module;       // path to the first .lmod to load (editor or game)
};
```

### Functions

```c
// Boot the kernel. Blocks until the window is closed or LGE_Shutdown() is called.
// Called once by the platform bootstrap — never by extensions or game code.
void LGE_Boot(const LGE_BootConfig& cfg);

// Request a clean shutdown. Safe to call from any thread or Lucid callback.
// The kernel finishes the current frame, calls on_unload on all live modules,
// then exits the frame loop.
void LGE_Shutdown();

// Returns the engine version as a packed uint32: 0xMAJORMINORPATCH
// Use this to check compatibility before calling version-sensitive APIs.
uint32_t LGE_GetVersion();
```

### Lucid-side (`api.kernel`)

```lucid
-- Read engine branding assets (logo, name, version string)
let logo    &Texture = api.kernel:get_branding_logo()
let name    string   = api.kernel:get_engine_name()     -- "Lucid Engine"
let version string   = api.kernel:get_version_string()  -- "1.0.0"

-- Request shutdown from Lucid code (e.g. File > Quit menu item)
api.kernel:shutdown()
```

### Notes
- `LGE_Boot()` never returns until shutdown — everything after it in the bootstrap's `main()` is dead code.
- `LGE_Shutdown()` is the only safe way to exit. Calling `exit()` directly skips module cleanup and can corrupt open VFS bundles.

## 2. ECS (`lge_ecs.h`)

**Lucid namespace:** `api.ecs`

The data backbone of every scene. Entities are `uint64_t` IDs; components are POD structs stored in contiguous archetype arrays. Systems iterate over matching component sets.

### Types

```c
typedef uint64_t EntityID;
typedef uint32_t ComponentType;   // returned by LGE_RegisterComponent()

// 0 is the null/invalid entity — never a valid EntityID
#define LGE_NULL_ENTITY ((EntityID)0)

// Passed to LGE_ForEach — receives a flat slice of matching entities
typedef void (*LGE_ForEachCallback)(
    EntityID*  entities,       // array of matching entity IDs
    void**     components,     // parallel array: components[i] is a pointer to the
                               // i-th requested component type for entities[i]
    uint32_t   count           // number of entities in this archetype slice
);
```

### Functions

```c
// Register a new component type. Call once at extension/game load time.
// name    — human-readable name shown in the editor inspector
// size    — sizeof the component struct
// align   — alignof the component struct
// Returns a ComponentType handle used in all subsequent ECS calls.
ComponentType LGE_RegisterComponent(const char* name, size_t size, size_t align);

// Create a new empty entity. Returns LGE_NULL_ENTITY on failure (out of memory).
EntityID LGE_CreateEntity();

// Destroy an entity and all its components. Safe to call mid-iteration
// (the entity is marked dead and removed after the current ForEach completes).
void LGE_DestroyEntity(EntityID id);

// Add a component to an entity. Returns a pointer to the zeroed component memory.
// Moves the entity to a new archetype bucket — O(1).
// Calling on an entity that already has this component returns the existing pointer.
void* LGE_AddComponent(EntityID id, ComponentType type);

// Get a pointer to an entity's component. Returns nullptr if the entity does not
// have this component type.
void* LGE_GetComponent(EntityID id, ComponentType type);

// Remove a component from an entity. Moves the entity to a new archetype bucket.
// No-op if the entity does not have this component.
void LGE_RemoveComponent(EntityID id, ComponentType type);

// Returns true if the entity currently has the given component type.
bool LGE_HasComponent(EntityID id, ComponentType type);

// Iterate over all live entities that have ALL of the requested component types.
// The callback is invoked once per archetype bucket — not once per entity.
// types     — array of ComponentType values (the query)
// type_count — length of types array
void LGE_ForEach(
    ComponentType*      types,
    uint32_t            type_count,
    LGE_ForEachCallback callback
);

// Returns how many live entities currently exist in the world.
uint32_t LGE_EntityCount();
```

### Lucid-side (`api.ecs`)

```lucid
-- Lucid components are registered automatically by the compiler from struct definitions.
-- The @component attribute marks a struct as an ECS component.

@component
struct HealthComponent {
    max    int   = 100
    current int  = 100
    regen  float = 0.5
}

-- Create and destroy entities
let entity EntityID = api.ecs:create_entity()
api.ecs:destroy_entity(entity)

-- Add, get, and check components
let health &HealthComponent = api.ecs:add_component(entity, HealthComponent)
let health &HealthComponent = api.ecs:get_component(entity, HealthComponent)
let has    bool             = api.ecs:has_component(entity, HealthComponent)

-- Iterate matching entities (equivalent to LGE_ForEach)
api.ecs:for_each([HealthComponent, TransformComponent], (entity, health, transform) = {
    health.current = health.current + health.regen
})
```

### Notes
- Never hold a raw component pointer across a frame — archetype moves (from `AddComponent` / `RemoveComponent`) can invalidate pointers.
- `LGE_DestroyEntity` mid-`ForEach` is safe; double-destruction is a no-op.
- All core engine components (`TransformComponent`, `MeshComponent`, etc.) are pre-registered at boot with fixed `ComponentType` values defined in `lge_components.h`.

## 3. Rendering / RHI (`lge_render.h`)

**Lucid namespace:** `api.render`

Abstracts all Vulkan GPU work. Upload textures and meshes, submit draw calls, manage the frame lifecycle. The RHI handles swapchain management, pipeline caching, and memory allocation (via VMA) internally.

### Types

```c
typedef uint32_t TextureID;   // handle to a GPU texture in the bindless array
typedef uint32_t BufferID;    // handle to a GPU vertex/index buffer
typedef uint32_t ShaderID;    // handle to a compiled shader/PSO

#define LGE_INVALID_ID ((uint32_t)0)  // null handle for all RHI types

enum PixelFormat {
    LGE_FORMAT_RGBA8,     // standard 8-bit-per-channel color
    LGE_FORMAT_SRGB8,     // sRGB color (gamma-corrected)
    LGE_FORMAT_R32F,      // single-channel 32-bit float (heightmaps, masks)
    LGE_FORMAT_DEPTH32F,  // depth buffer
};

struct Vertex {
    float position[3];   // XYZ
    float normal[3];     // surface normal
    float uv[2];         // texture coordinates
    float tangent[4];    // XYZ + handedness (W)
};
```

### Functions

```c
// --- Frame lifecycle (called by kernel.cpp only, not by extensions) ---

void LGE_RHI_BeginFrame();   // acquire next swapchain image, reset command buffers
void LGE_RHI_EndFrame();     // finalize and submit the command buffer
void LGE_RHI_Present();      // present the swapchain image; handles window resize

// --- Texture management ---

// Upload pixel data to the GPU. Returns a TextureID for use in draw calls.
// pixels  — raw pixel data in the specified format
// w, h    — dimensions in pixels
// Returns LGE_INVALID_ID on failure.
TextureID LGE_UploadTexture(const void* pixels, uint32_t w, uint32_t h, PixelFormat fmt);

// Free a GPU texture. The TextureID is invalid after this call.
void LGE_FreeTexture(TextureID id);

// --- Mesh / buffer management ---

// Upload vertex and index data to the GPU. Returns a BufferID.
BufferID LGE_UploadMesh(
    const Vertex*   verts,    uint32_t vcount,
    const uint32_t* indices,  uint32_t icount
);

// Free a GPU buffer. The BufferID is invalid after this call.
void LGE_FreeMesh(BufferID id);

// --- Draw calls (valid between BeginFrame and EndFrame) ---

// Submit a mesh draw call with an albedo texture and world transform.
void LGE_DrawMesh(BufferID mesh, TextureID albedo, const float transform[16]);

// Submit a raw GPU canvas draw (used by api.ui:create_canvas() and custom render hooks).
void LGE_DrawCanvas(TextureID render_target, const float transform[16]);

// --- Shader / PSO management ---

// Compile and cache a shader pair. Returns a ShaderID.
// Expensive on first call (compiles SPIR-V); subsequent calls return the cached PSO.
ShaderID LGE_CompileShader(const char* vert_spirv_path, const char* frag_spirv_path);

// Override the default mesh shader for a draw call.
void LGE_SetShaderOverride(ShaderID id);
void LGE_ClearShaderOverride();

// --- Screen / viewport ---

// Returns current backbuffer dimensions.
uint32_t LGE_GetRenderWidth();
uint32_t LGE_GetRenderHeight();
```

### Lucid-side (`api.render`)

```lucid
-- Hook into the render pipeline (e.g. add post-processing, override shaders)
api.render:on_post_process((frame &Texture) = {
    -- frame is the rendered scene before present — apply effects here
})

-- Create a Vulkan canvas for raw GPU drawing (used by custom editor tabs)
let canvas &Canvas = api.ui:create_canvas(tab)

-- Override shaders for a material
let shader ShaderID = api.render:compile_shader("shaders/cel.vert", "shaders/cel.frag")
api.render:set_shader_override(shader)
```

### Notes
- Draw calls submitted outside `BeginFrame`/`EndFrame` are silently dropped.
- `LGE_CompileShader` caches by file path — changing the file without renaming it requires calling `LGE_InvalidateShaderCache()` to force recompilation.
- All textures are registered into the global GPU bindless array on upload; the `TextureID` is their index in that array.

## 4. Physics (`lge_physics.h`)

**Lucid namespace:** `api.physics`

Wraps Jolt Physics. Create bodies attached to entities, apply forces, perform raycasts, and receive collision callbacks. Jolt writes simulation results back into `TransformComponent` each frame; the Render system reads from there. Jolt and Vulkan never communicate directly.

### Types

```c
typedef uint32_t BodyID;

enum MotionType {
    LGE_MOTION_STATIC,    // immovable — walls, floors
    LGE_MOTION_DYNAMIC,   // fully simulated — rigidbodies
    LGE_MOTION_KINEMATIC, // moved by code, not simulation — elevators, moving platforms
};

enum ColliderShape {
    LGE_COLLIDER_BOX,
    LGE_COLLIDER_SPHERE,
    LGE_COLLIDER_CAPSULE,
    LGE_COLLIDER_MESH,    // exact mesh shape — expensive; use for static geometry only
};

struct PhysicsBodyDef {
    MotionType    motion_type;
    ColliderShape shape;
    float         half_extents[3]; // for BOX: half-size on each axis
    float         radius;          // for SPHERE and CAPSULE
    float         height;          // for CAPSULE: cylinder height (excluding caps)
    float         mass;            // kg — ignored for STATIC
    float         friction;        // 0.0 (ice) to 1.0 (rubber)
    float         restitution;     // 0.0 (no bounce) to 1.0 (perfect bounce)
};

struct RaycastHit {
    EntityID entity;        // entity hit (LGE_NULL_ENTITY if nothing hit)
    float    position[3];   // world-space hit point
    float    normal[3];     // surface normal at hit point
    float    distance;      // distance from ray origin to hit point
};
```

### Functions

```c
// Create a physics body attached to an entity.
// The body's initial position is read from the entity's TransformComponent.
// Returns LGE_INVALID_ID if entity has no TransformComponent.
BodyID LGE_Physics_CreateBody(EntityID entity, const PhysicsBodyDef& def);

// Destroy a physics body. The entity remains; only the body is removed from Jolt.
void LGE_Physics_DestroyBody(BodyID id);

// Set the gravity vector for the entire physics world (default: 0, -9.81, 0).
void LGE_Physics_SetGravity(float x, float y, float z);

// Apply a continuous force to a body (Newtons — mass-dependent).
void LGE_Physics_AddForce(BodyID id, float fx, float fy, float fz);

// Apply an instant velocity change (mass-independent impulse).
void LGE_Physics_AddImpulse(BodyID id, float ix, float iy, float iz);

// Directly set body velocity. Useful for kinematic bodies.
void LGE_Physics_SetVelocity(BodyID id, float vx, float vy, float vz);

// Set body mass, friction, and restitution after creation.
void LGE_Physics_SetBodyProperties(BodyID id, float mass, float friction, float restitution);

// Cast a ray into the physics world. Returns true if something was hit.
// Populates out_hit with the closest hit.
bool LGE_Physics_Raycast(
```

## 8. Audio (`lge_audio.h`)

2D and 3D spatialized audio. Short sound effects (`.lsfx`) are fully loaded into RAM; long streams (`.lstream`) are decoded progressively. A dedicated mixing thread ensures audio never stutters under main thread load.

### Types

```c
void LGE_Audio_Unload(AudioSourceID id);

void LGE_Audio_Play(AudioSourceID id, bool loop);

// Pause playback. Resumable with LGE_Audio_Play.
void LGE_Audio_Pause(AudioSourceID id);

// Stop and reset to the beginning.
void LGE_Audio_Stop(AudioSourceID id);

bool LGE_Audio_IsPlaying(AudioSourceID id);

// --- Volume & mix ---

// Volume in [0.0, 1.0]. Applied multiplicatively with the global master volume.
void  LGE_Audio_SetVolume(AudioSourceID id, float volume);
float LGE_Audio_GetVolume(AudioSourceID id);

// Pitch multiplier. 1.0 = normal, 2.0 = one octave up, 0.5 = one octave down.
void  LGE_Audio_SetPitch(AudioSourceID id, float pitch);

// forward — normalized direction vector the listener is facing
void LGE_Audio_SetListenerTransform(float pos[3], float forward[3]);
```

### Lucid-side (`api.audio`)

```lucid
-- Load and play a sound effect
let gunshot AudioSourceID = api.audio:load_sfx("audio/sfx/gunshot.lsfx")
api.audio:play(gunshot, false)

-- Load and loop background music
let music AudioSourceID = api.audio:load_stream("audio/music/theme.lstream")
api.audio:set_volume(music, 0.6)
api.audio:play(music, true)

-- 3D spatialized footstep (attached to a moving entity)

api.audio:play(step, false)

```

### Notes
- `LGE_Audio_Play` posts a command to a lock-free queue — it returns immediately, and the mixing thread picks it up within the next mixing interval (~10ms).
- `AudioComponent` on an entity wraps an `AudioSourceID` and automatically calls `LGE_Audio_SetPosition` each frame from the entity's `TransformComponent`.
- Streams buffer the next chunk ahead of time; avoid `LGE_Audio_Stop` + `LGE_Audio_Play` in rapid succession on a stream (causes re-buffering stutter).

## 10. Script Manager (`lge_script.h`)

**Lucid namespace:** `api.script` (restricted — extension-facing only)

Loads, unloads, and hot-reloads compiled Lucid modules (`.lmod` / `.dll`). The file watcher and compiler subprocess are managed internally. External callers load and unload modules by path.

### Types

```c
typedef uint32_t ModuleHandle;
#define LGE_INVALID_MODULE ((ModuleHandle)0)

typedef struct LGE_ModuleInfo {
    const char* name;            // module display name (from extension.json or filename)

```

### Functions

```c
// Load a module from path. Calls its on_load() hook if it has one.
// Returns LGE_INVALID_MODULE if the file is missing or fails version check.
ModuleHandle LGE_Script_Load(const char* module_path);

// Unload a module. Calls its on_unload() hook, then frees the library.
void LGE_Script_Unload(ModuleHandle handle);

// Manually trigger a recompile of a source file, then hot-swap it.
// compile_path — path to the .luc source file
// Internally runs luc_compiler.exe, waits, then SwapModule on success.

```

### Notes
- Hot-reload is automatic when file watcher is enabled: save a `.luc` file → kernel recompiles → swaps the module between frames. No manual call needed from game code.
- The swap waits for the current frame to complete before replacing the live module — never interrupts mid-frame execution.
- `on_load(api)` and `on_unload()` are conventional Lucid function names. The script manager looks for them by symbol name after loading — they are optional.

```lucid
api.console:log("Player spawned at " + string(spawn_pos))
api.console:warn("Health below 10%")
api.console:error("Failed to load asset: " + path)

-- Register a custom command
api.commands:register("scene.reload", "Reload the active scene", (args string) = {
    scene:reload()
})

-- Execute a command programmatically
api.console:exec("physics.set_gravity 0 -20 0")
```

### Notes
- Commands registered by extensions are automatically unregistered when the extension is unloaded via `LGE_Ext_Unload`.
- The `args` string passed to callbacks is the raw text after the command name, unsplit. Each command is responsible for parsing its own arguments.
- IPC uses a local named pipe (Windows) or Unix domain socket (Linux) — not a real network socket. The port parameter is a logical identifier, not a TCP port.

## 13. Network (`lge_network.h`)

**Lucid namespace:** `api.network` / `api.net`

A provider-pattern network system. The kernel ships two built-in providers (raw TCP and UDP). Game developers can swap in a third-party provider (Steam, Epic Online Services, etc.) by filling an `LGE_NetworkProvider` struct and passing it to `LGE_Network_SetProvider`.

### Types

```c
typedef uint32_t ConnHandle;
#define LGE_INVALID_CONN ((ConnHandle)0)

typedef uint32_t LGE_SendFlags;
#define LGE_SEND_RELIABLE   ((LGE_SendFlags)(1 << 0))  // guaranteed delivery + ordering (TCP-style)
#define LGE_SEND_UNRELIABLE ((LGE_SendFlags)(1 << 1))  // best-effort, low-latency (UDP-style)
#define LGE_SEND_ENCRYPTED  ((LGE_SendFlags)(1 << 2))  // provider handles its own encryption

typedef enum LGE_NetworkEventType {
    LGE_NET_CONNECTED,
    LGE_NET_DISCONNECTED,
    LGE_NET_DATA_RECEIVED,
    LGE_NET_ERROR,
} LGE_NetworkEventType;

typedef struct LGE_NetworkEvent {
    LGE_NetworkEventType type;
    ConnHandle           conn;
    const uint8_t*       data;       // valid only for DATA_RECEIVED; null otherwise
    uint32_t             data_size;
} LGE_NetworkEvent;

// C-style "interface" for a network provider — a struct of function pointers.
// Extensions fill this struct and pass it to LGE_Network_SetProvider().
// This is the C equivalent of a virtual interface — no vtable, no inheritance,
// no C++ required. The same pattern as Vulkan's VkAllocationCallbacks.
typedef struct LGE_NetworkProvider {
    void* user_data;   // passed as first arg to every function; holds provider state

    int          (*initialize)(void* user_data);
    void         (*shutdown)(void* user_data);
    ConnHandle   (*connect)(void* user_data, const char* address, uint16_t port);
    void         (*disconnect)(void* user_data, ConnHandle conn);
    int          (*listen)(void* user_data, uint16_t port);
    void         (*send)(void* user_data, ConnHandle conn,
                         const uint8_t* data, uint32_t size, LGE_SendFlags flags);
    int32_t      (*receive)(void* user_data, ConnHandle conn,
                            uint8_t* buffer, uint32_t buffer_size);
    LGE_NetworkEvent (*poll_event)(void* user_data);
} LGE_NetworkProvider;
```

### Functions

```c
// Set the active network provider. Call once at extension load time (on_load).
// Built-in options: LGE_Network_GetTCPProvider(), LGE_Network_GetUDPProvider()
// Extensions pass a filled LGE_NetworkProvider struct for third-party backends.
void LGE_Network_SetProvider(const LGE_NetworkProvider* provider);

// Connect to a remote host (client mode).
ConnHandle LGE_Network_Connect(const char* address, uint16_t port);

// Start listening for incoming connections (server mode).
bool LGE_Network_Listen(uint16_t port);

// Disconnect a connection.
void LGE_Network_Disconnect(ConnHandle conn);

// Send data on a connection.
void LGE_Network_Send(ConnHandle conn, const uint8_t* data, uint32_t size, LGE_SendFlags flags);

// Poll for the next event. Returns an event with type=0 if the queue is empty.
// Call every frame to drain the event queue.
NetworkEvent LGE_Network_PollEvent();
```

### Lucid-side (`api.network`)

```lucid
-- Use the built-in UDP provider
api.network:set_provider(api.network.udp_provider)

-- Connect to a server
let conn ConnHandle = api.network:connect("192.168.1.10", 7777)

-- Send a packet
let packet [byte] = serialize_player_state(player)
api.network:send(conn, packet, LGE_SEND_RELIABLE)

-- Poll events each frame
let event NetworkEvent = api.network:poll_event()
if event.type == NetworkEventType.DataReceived {
    apply_remote_state(event.data)
}

-- Swap to Steam provider (from a Steam network extension)
api.network:set_provider(SteamNetworkProvider)
```

### Notes
- `LGE_Network_PollEvent()` must be called every frame to drain the queue — unread events are not buffered indefinitely.
- The kernel provides only raw TCP and UDP; reliable UDP, NAT traversal, lobbies, and matchmaking are the responsibility of third-party provider extensions.
- Permission `"network.client"` is required in `extension.json` to call `LGE_Network_Connect`; `"network.server"` is required to call `LGE_Network_Listen`.

## 14. Security (`lge_security.h`)

**Lucid namespace:** N/A — engine-internal only. Not exposed to extensions or game scripts.

Handles boot integrity checking, license validation, and VFS key derivation. Called once at boot — not a per-frame API.

### Types

```c
// C-style swappable license verification backend (see MasterPlan Decision 4).
// Fill this struct and pass it to LGE_Security_SetVerifier() to change the
// verification strategy. The default backend is the offline Ed25519 verifier
// baked into the kernel. An online verifier can be swapped in as an extension
// without changing any other kernel code.
//
// Same pattern as LGE_NetworkProvider — a struct of function pointers,
// no C++ required.
typedef struct LGE_LicenseVerifier {
    void* user_data;   // passed as first arg to verify(); holds verifier state

    // Return 1 if the license file is valid, 0 if it is not.
    int (*verify)(void* user_data, const char* license_path);
} LGE_LicenseVerifier;
```

### Functions

```c
// Swap the license backend. Default is the offline Ed25519 verifier.
// Pass a filled LGE_LicenseVerifier struct to override.
// Must be called before LGE_Security_VerifyBoot().
void LGE_Security_SetVerifier(const LGE_LicenseVerifier* verifier);

// SHA-256 self-check: hash luc_kernel.dll and compare against the baked-in value.
// Returns 0 (and logs) if tampered. Called first in LGE_Boot().
int LGE_Security_VerifyBoot();

// Verify the license file. Delegates to the active LGE_LicenseVerifier.
// license_path — path to the .lic file on disk
// Returns 1 if valid, 0 if not.
int LGE_Security_VerifyLicense(const char* license_path);

// Derive the 32-byte AES-256 key used to decrypt the .pck bundle.
// publisher_key — the encrypted master key from the .lic file
// machine_uuid  — hardware fingerprint (CPU ID, motherboard serial, etc.)
// out_aes_key   — caller-allocated 32-byte buffer; filled on success
bool LGE_Security_DeriveVFSKey(
    const uint8_t* publisher_key, size_t key_len,
    const char*    machine_uuid,
    uint8_t*       out_aes_key
);
```

### Notes
- The SHA-256 boot checksum (`VerifyBoot`) covers the `luc_kernel.dll` binary itself. An unexpected checksum aborts boot — this catches binary tampering without requiring a network call.
- `DeriveVFSKey` uses PBKDF2 + HKDF so the derived key is unique per publisher+machine combination. A license file copied to another machine produces a different key and fails to decrypt the bundle.
- `LGE_LicenseVerifier` is a C struct of function pointers — no C++ required to implement a custom verifier. An online verification extension fills the struct, passes it to `LGE_Security_SetVerifier`, and the kernel calls `verify()` through it (see MasterPlan Decision 4).

**Lucid namespace:** N/A — engine-internal only. Not exposed to extensions.

## 17. The Extension API Table (`lge_api.h`)

```c
#define LGE_VERSION_MAJOR 1
```

### Version Compatibility

| requested_version major | Kernel major | Result                                        |
| ----------------------- | ------------ | --------------------------------------------- |
| Equal                   | Equal        | ✅ Returns full API table                      |
| Lower                   | Higher       | ✅ Returns compatible subset (backward compat) |
| Higher                  | Lower        | ❌ Returns `nullptr` — extension is too new    |

### Notes
- Extensions include only `lge_api.h` — never individual subsystem headers. The full API is in one struct.
- Lucid extensions never call `LGE_GetAPI` directly — the kernel passes a pre-validated `api` object to their `on_load(api)` hook. The function table is the same data; the Lucid runtime just presents it via named namespaces (`api.ecs`, `api.fs`, etc.) instead of raw function pointers.
- New functions are appended to the end of `LGE_ExtensionAPI`. Old functions are never removed or reordered — only a major version bump can break backward compatibility.
